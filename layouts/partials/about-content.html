Selected Project Experience

Azure migration of a regulated care management SaaS platform
Quality Compliance Systems (QCS) · Cloud DevOps Engineer

Challenge: A regulated UK SaaS platform (~60k weekly users, 50M+ requests/week) running on 12 self-managed MySQL servers in private hosting.

Delivered: Migration to Azure UK South, with the platform built as code in Bicep and Ansible, CI/CD pipelines, Cloudflare, monitoring and certificate automation.

Outcome: 850+ tenant schemas consolidated into 5 highly available Azure Database for MySQL instances with no data loss. Deployments cut from ~30 to ~5 minutes.

Highly available AWS platform and cost reduction
Experis · Cloud DevOps Engineer

Challenge: An application platform that needed to stay available under load, with secure access controls, automated releases and infrastructure costs kept under control.

Delivered: A 3-tier AWS architecture (Auto Scaling, ELB, Route 53, multi-AZ RDS) provisioned with Terraform and secured with IAM roles, security groups and VPC segmentation, plus GitHub Actions CI/CD and a centralised AWS Backup strategy.

Outcome: Infrastructure spend cut by ~15% through rightsizing, removing idle resources and CloudWatch cost alerting.

Enterprise infrastructure and network delivery
Altran / Capgemini Engineering · Infrastructure & Network Consultant Engineer

Delivered infrastructure and network engineering projects for major enterprise clients, including Vodafone, Airbus, ENGIE, SFR, Bouygues Telecom and BNP Paribas.
